# isp-network-performance-analysis - end of Year Report
A full-year performance analysis for a regional Internet Service Provider covering user growth and churn, network uptime, support ticket trends, subscription performance, and revenue by location.

## Tools Used
- Python (pandas) — data reshaping and cleaning
- Power BI — data visualization
- Excel — data aggregation
- Canva — presentation design

## Repository Contents
- Cleaned datasets used in the analysis
- Python script for reshaping raw network uptime data

## Note on Data
All datasets have been anonymized. Company name and personally identifiable information have been removed or replaced with pseudonyms to protect proprietary information.
